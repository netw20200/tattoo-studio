========================================
  TATTOO STUDIO WEBSITE TEMPLATE
========================================

Thank you for purchasing this template.

This is a one-page website template for a tattoo studio
with parallax effects, animated menu, works catalog
loaded from CSV, lightbox gallery and contact block.


----------------------------------------
  HOW TO USE
----------------------------------------

1. Unpack the ZIP archive.

2. Open the folder and upload all files to your hosting
   (or use GitHub Pages / Netlify / any static host).

3. Open index.html in a browser to see the site.

No build tools or Node.js required.
Works as pure HTML + CSS + JavaScript.


----------------------------------------
  FOLDER STRUCTURE
----------------------------------------

index.html          - main page
demo.css            - all styles
products.csv        - catalog of works (edit this file)
images/             - put your photos here
universal-parallax.min.js
universal-parallax.js


----------------------------------------
  HOW TO EDIT THE CATALOG (WORKS)
----------------------------------------

1. Open products.csv in Excel, Google Sheets or any text editor.

2. Format:
   name,image,description,category

3. Example:
   Blackwork Sleeve,images/tattoo1.jpeg,Full arm blackwork piece,Blackwork
   Back Piece,images/tattoo2.jpeg,Large back tattoo,Realism

4. Save the file and refresh the website.
   New cards will appear automatically.


----------------------------------------
  HOW TO CHANGE PHOTOS
----------------------------------------

- Home background:     images/hero.jpg
- About background:    images/splach.jpeg (or your file)
- Works background:    images/tattoo-process.jpg
- Contact background:  images/Artists.jpeg

Replace files with the same names
or change the paths in index.html.

Demo images are for preview only. Replace them with your own before use.
----------------------------------------
  HOW TO CHANGE CONTACTS
----------------------------------------

Open index.html and find the block with id="contact".

Change:
- phone number
- email
- address
- website
- social media links (Instagram, Telegram, etc.)


----------------------------------------
  HOW TO CHANGE MENU ITEMS
----------------------------------------

Menu links are in index.html inside <nav class="menu">.

Sections use these IDs:
  #home
  #about
  #works
  #contact
